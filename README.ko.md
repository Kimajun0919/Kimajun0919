# 🧭 제품을 만드는 방식

### 01. Find the Core

기능보다 먼저  
**사용자가 실제로 겪고 있는 문제가 무엇인지** 찾습니다.

### 02. Make It Simple

복잡한 기술을 그대로 노출하기보다  
사용자가 쉽게 사용할 수 있는 경험으로 바꿉니다.

### 03. Build It

아이디어와 문서에서 멈추지 않고  
동작하는 프로덕트로 만듭니다.

### 04. Ship It

완벽한 제품을 기다리기보다  
사용자에게 전달하고 실제 반응을 확인합니다.

### 05. Improve It

데이터와 피드백을 바탕으로  
제품을 계속 발전시킵니다.
